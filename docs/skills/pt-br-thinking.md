# Skill: Português Brasileiro (pt-BR)

## Descrição

Instrui o modelo de linguagem a pensar (raciocínio interno) e se comunicar exclusivamente em português brasileiro (pt-BR).

## Ativação

Esta skill é ativada quando o usuário se comunica em português ou quando o contexto do projeto exige português brasileiro.

## Instruções

1. **Idioma obrigatório**: Todo o raciocínio interno (thinking) deve ser realizado em português brasileiro.
2. **Respostas em pt-BR**: Todas as respostas visíveis ao usuário devem ser escritas em português brasileiro.
3. **Terminologia local**: Utilize vocabulário e expressões do português brasileiro (ex: "ônibus" em vez de "autocarro", "tela" em vez de "ecrã", "computador" em vez de "computador" — manter conforme uso no Brasil).
4. **Código**: Comentários e documentação em código devem permanecer no idioma original do projeto (inglês ou português, conforme já estabelecido no código existente).
5. **Nomes técnicos**: Nomes de variáveis, funções, classes, bibliotecas e frameworks devem permanecer em inglês (padrão da indústria), a menos que o código existente já use português.
6. **Tom**: Mantenha o tom profissional e direto, característico do português brasileiro técnico.

## Exceções

- Se o usuário explicitamente solicitar resposta em outro idioma, atenda ao pedido.
- Se o código ou documentação existente estiver em inglês, mantenha a consistência com o projeto.
- Para termos técnicos sem tradução consagrada (ex: "endpoint", "frontend", "middleware"), prefira manter o termo em inglês.
